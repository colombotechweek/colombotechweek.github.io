# Colombo Tech Week

![Colombo Tech Week line illustration with builders gathering across the city.](assets/site/colombo-city-art.svg)

[Colombo Tech Week](https://colombotechweek.com) is a citywide builder week taking shape for founders, engineers, designers, investors, operators, and community hosts across Colombo, Sri Lanka.

The public website is intentionally simple while the program is being prepared. Follow the Luma calendar to get notified when updates open.

[Get notified on Luma](/#launch)

## Media Kit

Official logos, usage notes, colors, and typography are available at
[colombotechweek.com/media-kit](https://colombotechweek.com/media-kit/).

## What To Expect

- Community-hosted rooms across Colombo, Sri Lanka.
- Founder conversations, technical sessions, demos, and meetups.
- A public calendar that makes the week easy to discover and follow.
